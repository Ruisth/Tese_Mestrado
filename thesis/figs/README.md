# thesis/figs

Figures referenced by the Markdown mirror in `thesis/sections/`.

Originals live where they are produced:

| Origin | Location |
|---|---|
| Institutional logos | `thesis/latex/imagens/` |
| Diagrams | `diagrams/` (Mermaid sources) |
| Result figures | `experiments/results/figures/`, regenerated by `python -m egw_experiments analyze` |

Export copies here only when a section needs to reference an image directly.
Never edit an exported copy: fix the origin and export again, otherwise the
figure in the mirror and the figure in the PDF drift apart.

Empty until the campaign produces figures (no experimental data exists yet).
