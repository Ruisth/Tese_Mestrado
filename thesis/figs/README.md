# thesis/figs

> **Historical placeholder.** This folder belongs to the LaTeX conversion of 2026-09-17
> ([`../README.md`](../README.md)), which is not the current dissertation. It holds only this
> README: no figure was ever exported here. The figures of the current dissertation are in the
> student's Word file, outside this repository. The data behind its results are listed in
> [`../../docs/results.md`](../../docs/results.md).

The folder was meant for figures referenced by the Markdown mirror in `thesis/sections/`.

Originals were to live where they are produced:

| Origin | Location |
|---|---|
| Institutional logos and the research-process figure | `thesis/latex/imagens/` |
| Diagrams | `diagrams/` (Mermaid and PlantUML sources; earlier diagrams, see [`../../diagrams/README.md`](../../diagrams/README.md)) |
| Result figures of the planned campaign | `experiments/results/figures/`, regenerated by `python -m egw_experiments analyze`; the campaign was not run, and that folder holds only a placeholder file |

Export copies here only when a section needs to reference an image directly.
Never edit an exported copy: fix the origin and export again, otherwise the
figure in the mirror and the figure in the PDF drift apart.

**Dated note.** When this file was written (2026-08-11), it said the folder would stay empty until
the planned campaign produced figures, because no experimental data existed then. That campaign
was not run. The results obtained later, and their data, are indexed in
[`../../docs/results.md`](../../docs/results.md); none of them was exported here.
