# Experiments — campaign evidence tree

This directory holds the experimental campaign of the EGW thesis: the frozen
campaign plan and the evidence tree defined by the plan (section 5.8). All
tooling lives in `src/egw_experiments/` and is standard-library only for the
core analysis; `matplotlib` is an optional extra used exclusively for figures.

```text
experiments/
├── campaign_plan.json        # generated; fully enumerated ordered run list
└── results/
    ├── raw/<run_id>/         # immutable evidence, one directory per run
    │   ├── events.jsonl      # controller log (primary latency source)
    │   ├── sent_events.jsonl # simulator log (delivery-rate denominator)
    │   ├── resources.csv     # 1 Hz docker stats samples
    │   ├── manifest.json     # scenario, seed, commit, image digests,
    │   │                     # environment ref, config echo, timestamps,
    │   │                     # protocol version, exclusion field
    │   ├── environment.json  # host metadata captured at run time
    │   ├── logs/             # simulator stdout/stderr and raw outputs
    │   └── SHA256SUMS        # written last, covers every file above
    ├── processed/            # ALWAYS regenerated by the analyze command
    └── figures/              # ALWAYS regenerated by the analyze command
```

## Campaign workflow

1. **Plan** (once, before the campaign; frozen at gate G4 / tag `exp-v1`):

   ```bash
   python -m egw_experiments plan --master-seed 42
   ```

   Writes `campaign_plan.json`: every run of the frozen protocol
   (plan 7.1) with a stable `run_id`, a per-run seed derived from the
   master seed, and the load-sweep block in randomized order
   (`random.Random(master_seed)`). The same master seed always produces
   an identical plan; the file also tracks per-run `status`.

2. **Run** (N times, on the ARM64 VM, one planned run at a time):

   ```bash
   python -m egw_experiments run --run-id nominal-r01 \
       --broker localhost --username egw-simulator --ca-cert ca.crt
   ```

   Executes the simulator CLI as a subprocess (CONTRACTS section 7),
   samples `docker stats` at 1 Hz into `resources.csv`, waits the 60 s
   confirmation window (plan 7.3), collects the controller's
   `events.jsonl` for that `run_id` from `EGW_EVENT_LOG_DIR`, writes
   `manifest.json` and finally `SHA256SUMS`. The runner refuses to reuse
   an existing `results/raw/<run_id>/`.

   Conditions not driven by the simulator (QEMU boots, cold starts, twin
   creations) are measured by the deployment/platform procedures; their
   evidence is placed under `results/raw/<run_id>/` manually and the plan
   status is updated by hand.

3. **Freeze raw** (data freeze `data-v1`, gate G5): after the freeze,
   everything under `results/raw/` is immutable. No file in a raw run
   directory may be edited, added or deleted afterwards. Integrity is
   verifiable at any time:

   ```bash
   python -m egw_experiments verify-checksums
   ```

   Bulky raw data stays out of normal Git history but is preserved in a
   versioned archive with SHA-256 checksums and its location recorded in
   the manifest/release (plan 5.8).

4. **Analyze** (any number of times, reproducibly):

   ```bash
   python -m egw_experiments analyze
   ```

## Regeneration rule (plan 5.8 / 9.1)

`results/processed/` and `results/figures/` are never edited by hand.
The single `analyze` entrypoint deletes their contents and regenerates
everything from `results/raw/` alone:

- `processed/per_run.csv` — one row per run with the plan 7.3 metric
  definitions applied verbatim (sent/delivered/lost/duplicate/rejected,
  delivery rate, latency p50/p95/p99);
- `processed/resources_by_run.csv` — per-container CPU/memory aggregates;
- `processed/summary_by_condition.csv` — cross-run statistics (unit of
  analysis = run): mean, stdev, 95% CI via Student t (hardcoded t-table,
  documented in `analyze.py`; no scipy), median, p25/p75, min, max. The
  soak run is summarized descriptively without a CI (plan 7.3);
- `processed/saturation.json` — the plan 7.3 saturation evaluation per
  load (queue growth is recorded as TODO: not measurable with the current
  instrumentation);
- `figures/*.png` — generated only when `matplotlib` is importable
  (install with `pip install -e src[analysis]`); without it the command
  prints a notice, still regenerates all tables, and exits 0.

Re-running `analyze` after a fresh checkout plus the archived raw data
must reproduce every table and figure bit-for-bit from the same inputs.

## Excluded runs (plan 7.3)

A run may be excluded only for a proven cloud, instrumentation or
configuration failure, and the cause must be documented in that run's
`manifest.json` `exclusion` field (before the data freeze). Excluded runs
remain listed in `per_run.csv` with the flag and reason, but are removed
from summaries, saturation and figures. A slow run is never excluded for
its result alone. Repeats of an excluded condition use a new versioned
`run_id`; the original directory is kept.
